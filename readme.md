# Интерактивный счетчик (Counter)

## Описание программы
Проект представляет собой простейший интерактивный счетчик, созданный с использованием HTML, CSS и ванильного JavaScript. 
Приложение позволяет увеличивать или уменьшать значение на единицу с помощью кнопок. Интерфейс реагирует на изменения: меняет цвет фона окна результата в зависимости от значения, блокирует кнопки при достижении экстремальных значений и выводит предупреждающее сообщение.

## Как запустить
Для запуска программы не требуется установка дополнительного программного обеспечения или локального сервера:
1. Скачайте все файлы проекта в одну папку.
2. Найдите файл `index.html` и откройте его двойным кликом (он откроется в вашем браузере по умолчанию).
3. Нажимайте на кнопки **«+»** и **«-»** для изменения значения.

## Структура проекта
Проект состоит из следующих файлов, лежащих в одной корневой папке:

```text
counter_project/
```

## Реализованный функционал

В ходе выполнения задачи были реализованы следующие возможности:

### Пользовательский интерфейс (HTML/CSS)
* Кнопки «+» и «-», а также окно отображения результата.
* Фон страницы — линейный градиент. 
* Кнопки имеют радиальное скругление 5 пикселей.
* Окно результата выполнено в виде квадрата с крупным шрифтом.

### Логика на JavaScript (Ванильный JS)
* С использованием слушателей событий (`addEventListener('click')`) значение увеличивается на 1 при нажатии на «+» и уменьшается на 1 при нажатии на «-».

### Динамическое изменение стилей
* При положительном значении фон окна результата становится жёлтым.
* При отрицательном значении — зелёным.
* При значении «0» — красным.

### Ограничения и уведомления
* При достижении значения `10` кнопка «+» блокируется (становится неактивной).
* При достижении значения `-10` кнопка «-» блокируется.
* Если значение возвращается в пределы от `-9` до `9`, кнопки снова разблокируются.
* При достижении экстремальных значений (10 или -10) ниже кнопок появляется надпись: *«Вы достигли экстремального значения!»*.
